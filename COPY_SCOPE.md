# Copy boundary

This repository is an independent application copy. It contains the public website source, static assets, PostgreSQL schema and public records needed to present the catalogue.

It intentionally excludes the source website’s Git history, environment files, database credentials, payment and courier credentials, social/analytics tokens, customer records, user accounts, authentication sessions, orders, payments, quotations, coupons, WhatsApp data and other private operational data. Configure fresh target credentials before enabling any live payment, delivery, social or admin workflows.
